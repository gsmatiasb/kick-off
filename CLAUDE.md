# Kick Off

App instalável (PWA) para controlar pacotes de camisetas de futebol importadas. Leia `PROJETO.md` antes de qualquer mudança: ele traz as regras de negócio, os cálculos, o banco de dados e a forma de publicar.

- Responda ao dono em português.
- Todo o app está em `index.html` (HTML, CSS e JS puros, sem build).
- A cada mudança, aumente o número de `CACHE` em `sw.js`.
- Nunca coloque senhas ou a chave secreta do Supabase no repositório (ele é público). Só a chave publicável vai em `config.js`.
- Publicação: um push na branch `main` publica pelo GitHub Pages em https://gsmatiasb.github.io/kick-off/.
